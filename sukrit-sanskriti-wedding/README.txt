SUKRIT & SANSKRITI — WEDDING INVITATION
========================================

FILES
- index.html
- style.css
- images/engagement-1.png
- images/engagement-2.png

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser or use VS Code Live Server.

CUSTOMIZATION NOTES
- Names, family names, dates and ceremony list are filled using the details provided.
- Countdown is set to 21 November 2026 at 7:00 PM IST. Change the `wedding` date in index.html if the ceremony time differs.
- Event timings were not provided, so they have not been invented.
- The Google Maps link is a search link for Rajendra Palace, Khanjahapur near DCPS School. Verify the exact map pin before sending the invitation.
- Two uploaded engagement photos are included locally in the images folder.
- The venue decorative image uses an online Unsplash image; Google Fonts and that image need internet access.
- This is a static website suitable for GitHub Pages. No build process or framework is required.
